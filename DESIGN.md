# Group Control DESIGN.md

## What this is
iTechLounge portfolio administrators, delivery owners, employees, agents and third-party advisers use this product for portfolio register, crm, milestones, risk/dependency tracking, staffing and business compliance across uk, germany and other markets.

## Visual language
Keep existing source token system and information-dense portfolio operations layout. Optimise density with clear hierarchy instead of colour saturation; the source's CSS controls remain authoritative.

## Data truth and UX priority
Never merge projects because brands look similar; preserve canonical project IDs and role/tenant ownership. Surface due dates, blockers, evidence, activity author and jurisdiction separately, with no fabricated launch readiness or automation completion.

## Requirements
- Public pages have one primary task and truthful content. SaaS workspaces show queues, status, owner, cost/time, action and recoverable errors before ornamental charts.
- Preserve server-side role checks, private data, legal settings, audit trails and real money state; never substitute fake production values or disable gates for screenshots.
- Match current CSS tokens and component library, with coherent status colours and accessible text hierarchy.
- Validate at mobile 360/390px, tablet 768px, desktop 1440px; keyboard, screen reader, 200% zoom, focus, contrast and reduced motion. Inspect long text and missing records.
- Distinguish mockups, sandbox actions, queued jobs, deployed features and verified user outcomes.
